# MOVEMENTS

JUSTINE CORMIER

[View this project online](https://justjust11-bit.github.io/cart253/topics/instructions/INSTRUCTIONS-PROTOYPES-HERE/abstract-prototype/)

## Description

This prototype is an abstract work that uses motion and emulates 3d graphics. Blue circles rotate around the screen up and down, and there is a square in the middle that self rotates. Enjoy watching these interesting movements.
