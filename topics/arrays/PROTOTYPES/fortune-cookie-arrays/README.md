# FORTUNE COOKIE (ARRAYS)

JUSTINE CORMIER

[View this project online](https://justjust11-bit.github.io/cart253/topics/arrays/PROTOTYPES/fortune-cookie-arrays/)

## Description

Pick a fortune cookie from the cookie jar, have your fortune be read! The fortune is randomized.
This is refactored version of one of my conditionals prototypes. I focused on using arrays, and functions to tie the code together and reduce repetitiveness.
