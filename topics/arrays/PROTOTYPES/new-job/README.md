# New job!

JUSTINE CORMIER

[View this project online](https://justjust11-bit.github.io/cart253/topics/arrays/PROTOTYPES/new-job/)

## Description

You applied for a job you aren't qualified for! What's the worst that can happen, you can probably figure this out!
Visual novel-esque mini game, you click to progress the story, and use the UP and DOWN arrows when confronted with a choice to make a selection.
